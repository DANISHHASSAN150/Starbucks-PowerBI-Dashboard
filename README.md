# ☕ Starbucks Power BI Dashboard

## 📊 Project Overview

This project is an interactive **Starbucks Beverage Analysis Dashboard** created using **Microsoft Power BI**.

The dashboard analyzes Starbucks beverage data and provides insights into caffeine, calories, sugar, protein, and beverage categories.

## 🎯 Objectives

- Analyze Starbucks beverage categories
- Compare average caffeine levels across beverages
- Identify the top 5 highest-caffeine beverages
- Analyze average calories by beverage category
- Analyze beverage category distribution
- Provide interactive filtering using Protein Range and Beverage Preparation
- Present key insights through an interactive dashboard

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- CSV Dataset
- Data Visualization

## 📈 Dashboard Features

### KPI Cards

- Total Beverages

### Visualizations

- Average Calories by Beverage Category

- Beverage Category Distribution

### Filters

- Protein Range
- Beverage Preparation
