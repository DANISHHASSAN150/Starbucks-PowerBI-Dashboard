# ☕ Starbucks Power BI Dashboard

## 📊 Project Overview

This project is an interactive **Starbucks Beverage Analysis Dashboard** developed using **Microsoft Power BI**.

The dashboard analyzes Starbucks beverage data and provides insights into **caffeine, calories, sugar, protein, and beverage categories** through interactive visualizations and filters.

---

## 🎯 Objectives

- Analyze Starbucks beverage categories
- Compare caffeine levels across beverages
- Identify the top 5 highest-caffeine beverages
- Analyze average calories by beverage category
- Analyze beverage category distribution
- Explore nutritional information
- Provide interactive filtering using Protein Range and Beverage Preparation
- Present key insights through an interactive Power BI dashboard

---
